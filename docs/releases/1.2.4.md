# 礼记 1.2.4

发布日期：2026-10-31。

## 更新内容

- 重构回收站页面，按删除时间分组展示已删除的收支记录和联系人，并保留各分类总数。
- 收支记录可搜索姓名、事由和原账簿；联系人可搜索姓名、关系和电话。列表同时显示删除时间、原账簿、礼金日期或关联记录数量，便于找回误删内容。
- 记录和联系人支持左滑显示「恢复」「删除」，同一时间仅展开一行。右滑、点按其他区域、滚动、搜索、切换分类或进入管理时自动收起；滑动到尽头不会直接修改数据。
- 点击「管理」或长按条目可多选。全选仅作用于当前搜索结果，支持批量恢复和彻底删除；操作期间阻止重复提交，失败后保留选择以便重试。
- 恢复收支记录时，如对应联系人已删除，可选择同时恢复联系人；恢复联系人不自动恢复关联记录。彻底删除联系人前明确展示关联记录数量，写入前再次核对范围。
- 新增联系人回收站关联记录提示和删除范围保护，所有恢复、彻底删除操作均继续接入编辑保护。
- 适配窄屏、深色模式和放大字体；弹窗操作按钮在空间不足时改为纵向排列。
