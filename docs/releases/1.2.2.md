# 礼记 1.2.2

发布日期：2026-10-11。

## 更新内容

- 应用显示名称由「尚礼」调整为「礼记」，同步更新桌面标签、首页、关于页面、分享与导出文案。
- 修复设置编辑密码时取消、保存后弹窗不关闭的问题；输入弹窗正确返回表单内容，横屏及键盘弹出时可滚动操作。
- 补齐记录批量删除、账簿已有附件删除的编辑密码校验。取消或错误密码不删除数据。
- 账簿管理卡片收紧间距，将「当前使用」移到标题旁，删除「点击查看账簿详情」提示。
- 完善账簿详情新增记录与 PDF 导出入口；PDF 使用竖向礼账明细布局，支持保存、分享及分享失败重试。
- 整理联系人详情、编辑及关系类型管理页面，统一联系人称谓；导入仍兼容旧文件中的关系人列名。
- 更新文件选择、分享、偏好设置依赖及 Android 构建配置。

## 安装与数据边界

- 安装包仅支持 Android ARM64，最低 Android 7.0（API 24）。
- 应用包名仍为 `com.example.newshangli`。本次沿用现有调试证书签署 Release 包，签名与本地 1.2.1 安装包一致；尚未完成 Android 真机安装验收。
- 当前数据库结构为 schema 15，不提供历史结构升级，备份恢复仅支持当前结构。旧版用户请先在旧版导出并保存数据；不兼容的旧数据库可能需要清除应用数据后重新使用。重命名没有修改本地数据库文件名、偏好设置键或 WebDAV 默认目录。
- 应用保持本地优先，无账号和云同步；可自行配置 WebDAV 整包备份。自动备份后台调度及鸿蒙设备支持尚未实现。
