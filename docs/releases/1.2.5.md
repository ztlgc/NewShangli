# 礼记 1.2.5

发布日期：2026-11-08。

## 更新内容

- 修复导入记录中的事由未在「事由管理」显示的问题。CSV、Excel 和账簿粘贴导入会在记录提交时同步登记事由；同名事由自动去重，已有事由的停用状态和描述保留。
- 修复版首次打开数据库时，会从有效账簿和记录中一次性补齐缺失事由，无需重新导入；补齐标记随数据库备份保存，后续启动不会反复重建已删除事由。新安装仍预置原有 12 类常用事由。
- 调整统计页送礼事由环形图，让金额完整显示在内圈空白区域，大金额自动缩放，避免文字压住环形色带。
- 完善编辑保护：备份恢复和关系类型改名接入密码校验，同一编辑动作只校验一次；修复修改密码后保护状态变化、凭据保存失败及异常配置处理，加载失败时支持重试。
- 完善联系人和账簿编辑的失败保护，避免联系人加载失败后覆盖原数据，防止账簿重复保存及保存期间取消。
- 修复导入导出与备份恢复的数据完整性问题，覆盖头像和附件匹配、字段映射、备注空白、日期精度、导入日志和失败批次媒体清理。
- 统一备份生成与恢复的大小限制，强化当前数据库结构、约束、恢复保护副本完整性校验，以及 WebDAV 响应正文超时处理。
