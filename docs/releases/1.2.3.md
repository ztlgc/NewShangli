# 礼记 1.2.3

发布日期：2026-10-28。

## 更新内容

- 重新整理统计页：月、年和自定义时段切换，收支概览、同期对比、双柱趋势、送礼事由和往来排行集中展示；修复切换时段后旧结果与新标题错配的问题。
- 更新导入导出页面。导入支持字段匹配、前 20 行预览、可选图片 ZIP、疑似重复记录确认、任务历史及暂停继续；导出展示账簿和日期范围、Excel / ZIP 格式及实际记录数，分享失败后可重试。
- 修复导入字段忽略、任务取消状态和成功行计数，按成功处理的源数据行统计，避免把自动创建的联系人重复计入。
- 在收支录入或编辑过程中新增联系人，保存后自动回到原表单并选中新联系人，保留已经填写的金额和备注。
- 新建数据库默认事由扩充至 12 项，覆盖婚礼、生日、寿宴、满月、百日、周岁、乔迁、升学、开业、节日、探病和丧事。
- 日期选择器按月份实际四、五、六行调整高度，取消和确定按钮紧跟日期区域；完善窄屏、大字体及深色显示。
- 修复快捷金额连续点击后高亮不更新的问题，手动修改或清空金额时也同步更新。
- 重写 README，加入 9 张由虚构礼账数据渲染的实际页面截图，并提供独立的截图生成脚本。
