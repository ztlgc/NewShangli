## 必须明确的产品边界

1. **业务导出不是完整备份。** XLSX/业务 ZIP 只交换选定有效记录、联系人及相关部分账簿信息，不保留空账簿、全部账簿外观/附件、关系图、字典、回收站、所有创建/修改元数据和导入任务等完整状态。
2. **备份包是数据库+媒体+manifest，不是应用设置快照。** SharedPreferences 中的应用设置、编辑保护开关/密码哈希/盐、WebDAV 配置和凭据、备份历史/目录不会随包在新设备恢复；现有设备这些设置也不被包覆盖。这一范围已做实测。
3. **未完成的导入任务不支持跨设备继续。** 恢复将 pending/running/paused/failed 改为 canceled；源 CSV/XLSX、导入媒体 ZIP、日志不打包，任务中的旧路径仍会保留。
4. **无媒体恢复会清空媒体字段并替换目标媒体树。** 不会保留目标原有头像/附件；HTTP 媒体 URL 也被清空。其余数据全字段比较通过。
5. **ZIP CRC 和数据库 SHA 不等于来源认证。** 保持 CRC 的真实 payload 损坏会拒绝；人为换图并重打包计算正确 CRC 不会被视为损坏。仅中央目录 CRC 不一致、正文与本地 CRC 均完整的包也可能被接受；这两项按信任/元数据边界记录，没有计为本轮严重完整性缺陷。
