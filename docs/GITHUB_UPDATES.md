# GitHub Release 检查更新

## 使用方式

- 仅当前 Android 实现支持读取安装版本和打开下载页面。启动后异步读取版本并检查更新，不阻塞数据库初始化或首页。
- 更新源固定为 `https://api.github.com/repos/ztlgc/NewShangli/releases/latest`，无需登录或内置 GitHub Token。
- 每 24 小时最多自动检查一次，失败也计入间隔。断网、超时、限流等自动检查失败保持安静；「设置 → 检查更新」可立即重试，不受间隔或忽略设置限制。
- 草稿、预发布和没有已上传 APK 附件的 Release 不提示更新。
- 发现更新后显示当前完整版本、最新完整版本和 Release 说明，支持「前往下载」「稍后」「忽略此版本」。说明按纯文本显示，可滚动查看。
- 自动检查结果返回时若正在其他页面或应用已切入后台，等回到主页和前台后再提示。请求和弹窗共用操作锁，避免重复点击产生多个弹窗。
- 「前往下载」打开仓库的 Release 页面，由浏览器下载 APK，再由 Android 系统确认安装。没有应用内下载进度或静默安装。

## 版本约定

项目版本采用 `主版本.次版本.修订号+构建号`，例如 `1.2.5+2008`。

| 当前版本 | 发布标签 | 是否提醒 |
| --- | --- | --- |
| `1.2.5+2008` | `1.2.5+2009` | 是 |
| `1.2.5+2008` | `v1.2.5+2009` | 是，显示时移除 v 前缀 |
| `1.2.5+2008` | `1.2.5+2008` | 否 |
| `1.2.5+2008` | `1.2.5` | 否，旧标签的构建号按 0 比较 |
| `1.2.5+2008` | `1.2.6+2010` | 是 |
| `1.2.5+2008` | `1.2.4+2010` | 否 |

比较依次检查前三段，再比较数值构建号；本项目明确让 `+` 后的数字参与更新排序，区别于标准 SemVer 对 build metadata 的处理。忽略设置按规范化后的完整版本保存，只屏蔽这一版本的自动提醒。

## 发布新版本

1. 小修复只递增 `pubspec.yaml` 的构建号，例如 `version: 1.2.5+2009`；较明显的功能变化再调整前三段。构建号在所有正式发布之间持续递增。
2. 构建 APK。正常构建会从 `pubspec.yaml` 取版本，使用 `--build-name` / `--build-number` 覆盖时，Release 标签必须与最终构建值一致。
3. GitHub Release 的 tag 使用完整版本，例如 `1.2.5+2009`，标题也建议使用完整版本。上传对应 APK 和既有的校验文件，填写更新说明，再发布正式版。
4. 将该 Release 明确标记为 **Latest**。GitHub 和通用 SemVer 工具可能不使用 `+` 后的构建号排序，客户端使用 GitHub 的 Latest 正式版接口，不自行扫描所有历史 Release。
5. 保持包名及签名证书连续。Android 安装包的 versionCode 必须比上次发布高；同一架构沿用现有构建方式和持续递增的构建号。
6. 在旧版手机上手动检查，确认完整版本号、更新说明和下载链接，再验证覆盖安装及本地数据保留。

现有旧安装包没有更新功能，无法通过新功能自行获取首次升级；需要用户先手动安装包含此功能的版本。

## Android 构建号

Flutter 的 `--split-per-abi` 会对 APK versionCode 增加 ABI 偏移。例如现有 ARM64 包的 versionCode 为 `4008`，原始 Flutter 构建号为 `2008`。不能把 `4008` 与 Release 标签中的 `+2009` 直接比较。

Gradle 将原始 `flutter.versionName` 和 `flutter.versionCode` 写入应用资源，由 `liji/app_update` 平台接口读取，界面因此显示 `1.2.5+2008`，同时兼容构建参数覆盖。Android 系统仍使用原有 versionCode 进行安装判断，不改变已有安装包的版本编码方式。

## 代码与验证入口

- `lib/update/app_version.dart`：完整版本解析及数值比较。
- `lib/update/github_release.dart`：正式版和 APK 筛选、固定仓库地址校验、HTTP 请求。总请求超时 15 秒，响应正文最大 512 KiB。
- `lib/update/app_update_service.dart`：版本读取缓存、自动检查间隔、忽略设置、手动检查。
- `lib/platform/app_update_platform.dart`、`android/app/src/main/kotlin/com/example/newshangli/MainActivity.kt`：Android 版本读取及浏览器跳转。
- `lib/ui/app_update_host.dart`：启动检查、操作锁、延后提示、弹窗与失败反馈。
- `test/update/`、`test/ui/app_update_test.dart`：版本、网络、限流、忽略与界面回归测试。
