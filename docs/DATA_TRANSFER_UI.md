# 数据导入与导出

页面按已确认的设计实现，使用当前 Flutter / Forui 主题、白色卡片和固定底部操作区。

## 导入

- 支持选择 XLSX / CSV、下载两种格式的模板、核对字段、预览前 20 行和选择可选的图片 ZIP。
- 主页面显示关键字段与两行摘要。字段匹配弹层展示全部可配置字段；预览弹层可横向查看全部列。
- `import_field_mapping.dart` 负责常见表头自动匹配及必要字段检查。单表数据使用“数据类型”区分礼金记录和联系人；双工作表 Excel 按表名识别。预览不是整份文件的有效性验证，执行时仍逐行检查。
- 映射的 `null` 表示自动使用原有列名，空字符串表示明确“不导入”。该选择会持久化到导入任务，并在断点恢复时保留。
- 导入启动时立即锁定操作，防止重复提交。疑似重复记录由用户选择保留或跳过；处理结果显示实际计数和日志。
- 暂停、失败后继续使用原任务及断点。取消和离开页面均明确说明已提交数据保留；取消任务不可继续。任务历史支持查看结果与继续未完成任务，状态使用中文显示。
- 成功计数按成功处理的源数据行累计，不额外计算一条礼金记录自动创建的联系人。已有任务保存的历史计数不作重写。
- CSV 与 Excel 使用同一套头像/附件导入规则。未提供媒体 ZIP 时只导入业务数据，并在处理日志中说明未设置的头像/未导入的附件，警告不重复计为跳过或失败行；提供 ZIP 后缺少指定文件或存在同名歧义则中断当前未提交批次，需补全文件或填写 ZIP 内精确路径后重试。
- 附件字段支持自定义列名映射；备注保留首尾空白。官方模板通过同一联系人 ID 关联示例联系人与礼金行。处理日志顺序写入，任务结束前全部完成；失败批次已落盘的媒体会清理，已提交批次的媒体保留。

## 导出

- 支持全部账簿或指定账簿、所有时间或自定义起止日期，截止日期包含当天。
- 默认账簿沿用现有业务口径，包含其他账簿的送礼记录；选择器和页面均明确显示这一点。
- `DataExportService.inspectScope` 与实际导出共享范围查询，排除已删除实体。导出文件记录数从实际读取的内容取得。
- Excel 导出记录与联系人，头像及附件保留原路径供查看；导入不会读取这些本机路径。需要一并携带图片时请使用 ZIP，ZIP 与其中的表格通过导入页配合恢复图片。
- 使用不确定进度指示，不显示模拟百分比。生成后展示文件名、大小和实际记录数，再由用户打开系统分享。
- 分享失败保留已生成文件，可直接重试；文件丢失时提示重新导出。更改范围或格式会清除旧结果，避免分享错误的文件。
- 业务导出用于查看和整理，不替代完整数据库备份。
